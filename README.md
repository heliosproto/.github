# .github

This repository holds default community health files and the org profile for [Helios Protocol](https://github.com/heliosproto).

- [`profile/README.md`](./profile/README.md) — renders on the org profile page at [github.com/heliosproto](https://github.com/heliosproto)
- [`FUNDING.yml`](./FUNDING.yml) — adds the "Sponsor" button to every repo in the org

If you're looking for the project itself, head to [**heliosproto/heliosproto**](https://github.com/heliosproto/heliosproto).
