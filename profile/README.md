# Helios Protocol

**Smart-account-native infrastructure for the Stellar ecosystem.**

We're building the first wallet stack where Soroban smart accounts are the primary identity, not a bolt-on. Passkey login, session keys, social recovery, sponsored transactions, and a plugin architecture for composable account policies.

## What we're shipping

| Repo | Status | What |
|---|---|---|
| [**heliosproto**](https://github.com/heliosproto/heliosproto) | Early development | The monorepo — smart contracts (Rust/Soroban), wallet (Next.js + browser extension), backend services (Python/FastAPI), and SDKs |
